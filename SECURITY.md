# Security Policy

## Supported versions

Only the latest commit on the `main` branch is actively supported with security updates. We recommend keeping your plugin installation up to date.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |
| older   | No        |

## Reporting a vulnerability

If you discover a security vulnerability in ascii-ui.nvim, please report it privately so we can fix it before details are made public.

**Preferred method:** open a private security advisory on GitHub.

- [Report a vulnerability](https://github.com/ascii-ui/ascii-ui.nvim/security/advisories/new)

If GitHub Security Advisories are not available to you, send an email to the maintainers at **security@ascii-ui.dev**. Please include a clear description of the issue, steps to reproduce, and any suggested fixes.

## Response process

1. We will acknowledge receipt of your report within 5 business days.
2. We will investigate and aim to provide an initial assessment within 14 business days.
3. Once a fix is ready, we will coordinate disclosure and credit you unless you prefer to remain anonymous.

## Safe harbor

We consider vulnerability research and reporting to be protected activity. We will not take legal action against anyone who reports vulnerabilities in good faith and follows this policy.
